# 数据处理

- **数据**：MovieLens 1M，6,040 位用户、3,883 部目录电影、1,000,209 条评分，评分范围 1–5。实际有评分电影为 3,706 部。
- **清洗**：检查缺失、评分范围、时间戳、有效 ID 和重复记录；本次检查未删除记录。
- **划分**：按每位用户的时间戳组，约 80%/10%/10% 分为训练、验证、测试；同一时间戳不跨集合。实际分别为 799,086、100,613、100,510 条。
- **标签与输入**：评分 ≥4 为正反馈。ID 映射仅用训练集拟合，得到 6,040×3,667 的评分/正反馈矩阵、电影类型特征及高分电影序列。
- **共同评估**：验证 5,776 人、测试 5,765 人；从训练目录中排序，过滤全部已评分电影，包括低分电影。不采样评估负例。
- **历史**：验证使用训练历史，测试使用训练＋验证历史；模型参数均仅在训练集学习。

**讲解句**：先按用户时间划分，再构造训练特征，三种算法共用用户与候选规则，避免直接使用测试标签训练。

**边界**：这是按用户的时间划分，不是全局日历划分；时间戳是提交评分时间，不能视作准确观影顺序。主指标只评估有训练历史及暖启动高分目标的用户。
