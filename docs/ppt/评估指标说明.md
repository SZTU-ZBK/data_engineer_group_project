# 评估指标：Precision、Recall、NDCG

记用户的前 K 个推荐为 R，留出集中的可评估高分电影为 T。T 只包含评分 ≥4、属于训练目录、且历史未评分的电影。

| 指标 | 定义 | 回答的问题 |
|---|---|---|
| Precision@K | 命中数量 / K | 推荐的电影中，有多少是已知高分目标？ |
| Recall@K | 命中数量 / 用户的全部可评估高分目标数量 | 用户的高分目标被找回了多少？ |
| NDCG@K | DCG@K / IDCG@K | 高分目标是否排在推荐列表前面？ |

`DCG@K = Σ[rᵢ / log₂(i+1)]`，命中时 `rᵢ=1`，否则为 0。IDCG 将 `min(K, |T|)` 个命中放在最前面后计算，作为归一化上限。

**例子**：前五推荐为 A、B、C、D、E，目标为 A、C、F。命中 A、C，则 Precision@5=40%，Recall@5=66.67%，NDCG@5≈0.704。

三者均越高越好，范围为 0–1；每位用户分别计算，再取平均。主图使用 K=10，原始表同时保存 K=5。

**解释边界**：未评分电影只是不计为已知命中，不能判定为不喜欢。低 Precision 不等于低实际满意度。训练 loss 用于训练或选模，不作为本资料包的推荐质量评估指标。
