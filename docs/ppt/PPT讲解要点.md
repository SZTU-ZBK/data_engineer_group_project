# PPT 讲解要点

## 汇报口径

- 比较的是当前各自选定配置的效果：ItemCF 无训练轮次，LightFM 为 10 轮，LRURec 权重训练到第 50 轮。数据划分、评估用户、候选及过滤规则相同，训练目标、拟合样本和预算不同，不能宣称是同等训练预算下的比较。
- LightFM 当前只用 ID，相当于协同矩阵分解；不要称为使用电影属性的混合推荐，也未验证论文的冷启动效果。LRURec 为适配课程数据协议的核心结构实现，不是论文指标复现。
- LRURec 训练窗口 50、推理窗口 100；推理窗口是在同一份权重上选择的。窗口差异很小，不作为主要创新或显著提升来宣传。
- 主要结果是三种模型当前的 Precision、Recall、NDCG。未评分只代表未知；不能将未命中率说成用户不喜欢的比例。单随机种子也不能证明结果对所有训练运行都稳定。

课程说明要求展示数据形状、缺失、字段类型与唯一值，并为选定用户展示至少五部未评分电影的标题和类型。新增两张图及 `data/dataset_info.csv`、`data/column_info.csv` 对应这些展示内容。

交互展示可直接打开 `notebooks/04_lrurec.ipynb`，修改 `USER_ID` 后运行推荐单元格；PPT 中推荐对照图是展示结果，现场 notebook 操作才体现交互功能。课程另需技术报告及源码，PPT 资料包不替代这两项提交。
